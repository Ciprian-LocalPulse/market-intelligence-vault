# Executive start here

**Market Intelligence Vault · Quality Hardening Release 1.0.1**

This release is a research framework with a fictional demonstration. It contains no verified
real-market intelligence and no approved capital recommendation.

## First five minutes

1. Read the [worked decision brief](12_examples/fictional_decision_brief.md): proposed choice,
   first-stage cap, strongest contrary evidence and stop rule.
2. Read the [executive summary](EXECUTIVE_SUMMARY.md): compare the strongest opportunity with its
   confidence gate and the three main risks.
3. Check the decision status. PROPOSED is not approved. A low-confidence TEST is a request to learn.

## Next ten minutes

Open the [claims register](08_evidence/claims_register.csv) for the weakest dependency and freshness.
Trace it through the [evidence map](08_evidence/claim_evidence_map.csv) and
[source library](08_evidence/source_library.csv). Review contradicting evidence before attractive scores.
Use the [action plan](07_strategy/action_plan.csv) to check owners, prerequisites and success metrics.

## Four questions before committing

- What exact decision and capital/time cap are being requested?
- Which missing observation could reverse that choice?
- What could cause an unacceptable loss, and who owns the response?
- What measured gate unlocks the next stage, and who can approve it?

For a live engagement, the completed brief and approval record replace this demonstration route.
Technical setup and data entry belong in [QUICK_START.md](QUICK_START.md); the executive does not
need to read all repository documents before reviewing a decision.
