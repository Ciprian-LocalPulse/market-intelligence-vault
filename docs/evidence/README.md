# Evidence review route

Read [research standards](../../RESEARCH_STANDARDS.md), [source evaluation](../../SOURCE_EVALUATION.md),
[citation policy](../../CITATION_POLICY.md) and [confidence policy](../../CONFIDENCE_SCORING.md).
The canonical trail is source_library → evidence_register → claim_evidence_map/claims_register →
recommendations. Keep supporting, contradicting and contextual relationships distinct. Origin-group
independence and semantic relevance require human review. A syntactically valid URL or matching archive
hash cannot establish factual truth. See the [data contract guide](../architecture/DATA_CONTRACTS.md).
