# Scoring review route

The active heuristic model is 1.0.1, while the interactive product release is 1.1.0.
Read [confidence](../../CONFIDENCE_SCORING.md), [opportunities](../../OPPORTUNITY_SCORING.md),
[risks](../../RISK_SCORING.md), [methodology](../../METHODOLOGY.md) and [decision rules](../../DECISION_FRAMEWORK.md).
Weights and anchors are canonical CSVs in 09_scores; per-factor assumptions are in factor_assessments.csv.

Whole-point dashboard displays do not change unrounded model classifications. The dashboard's
competitor-pressure presentation bands (40/60/80) differ from the historical methodology's
pressure descriptors (35/55/75); these are disclosed presentation rubrics, not a changed formula.
Do not compare labels without naming the rubric. No index is an empirically calibrated probability.
